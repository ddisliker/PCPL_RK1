# PCPL - Рубежный контроль № 1

**Курс:** ПиК ЯП  
**Вариант запросов:** В  
**Вариант предметной области:** 20 - Деталь / Поставщик

## Задания

1. Вывести детали, название которых начинается с буквы «А», и названия их поставщиков.
2. Вывести поставщиков с минимальной ценой деталей, отсортировав по минимальной цене.
3. Вывести связанные детали и поставщиков для связи многие-ко-многим, отсортировав по поставщикам.

## Запуск

```bash
python main.py
```

Файл `pcpl_rk_1.pdf` содержит исходный код программы и результаты ее выполнения.
